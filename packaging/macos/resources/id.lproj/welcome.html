Mordred

Ini akan menginstal Mordred untuk Anda, orang yang sedang masuk saat ini: Hermes miliknya sendiri, model Bonsai lokal, kunci dan enkripsi, serta dua server yang berjalan saat Anda masuk.

  • Anda tidak perlu mengetik apa pun. Saat diminta oleh macOS, konfirmasikan dengan Touch ID.
  • Model Bonsai yang sudah ada di ~/models/bonsai/models akan digunakan apa adanya. Jika tidak ada, model kecil (sekitar 1 GB) akan diunduh, dan Anda akan ditanya sebelum model besar (sekitar 8 GB) diunduh.
  • File cadangan disimpan ke folder Unduhan Anda. File itu saja sudah cukup untuk memulihkan kunci Anda di Mac lain: simpan salinannya di tempat yang aman dan pribadi.

Proses ini memerlukan beberapa menit; selama itu penginstal menampilkan “Menjalankan skrip paket”.
