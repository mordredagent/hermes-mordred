Mordred

Ceci installe Mordred pour vous, la personne actuellement connectée : son propre Hermes, les modèles Bonsai locaux, les clés et le chiffrement, ainsi que les deux serveurs qui démarrent lorsque vous vous connectez.

  • Vous n’aurez rien à saisir. Lorsque macOS le demande, confirmez avec Touch ID.
  • Les modèles Bonsai déjà présents dans ~/models/bonsai/models sont utilisés tels quels. Sinon, le petit modèle (environ 1 GB) est téléchargé, et la question vous est posée avant de télécharger le grand (environ 8 GB).
  • Un fichier de sauvegarde est enregistré dans votre dossier Téléchargements. Ce fichier suffit à lui seul pour restaurer vos clés sur un autre Mac : conservez-en une copie dans un endroit sûr et privé.

Cela prend quelques minutes ; pendant ce temps, le programme d’installation affiche « Exécution des scripts du paquet ».
